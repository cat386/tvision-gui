# 11. Диалог настроек: тема, шрифт, размер шрифта

tvision-gui даёт готовый **стандартный диалог настроек окна**. В нём
пользователь выбирает:

* **тему оформления** — палитру программы и 16 цветов окна;
* **шрифт** — любой моноширинный шрифт, установленный в системе, или
  системный по умолчанию;
* **размер шрифта** — от 6 до 96 логических пикселей.

```
╔═[■]═══════════════════════ Настройки ═════════════════════════╗
║ Тема                              Шрифт                       ║
║  Gruvbox                     ▲     Системный (по умолчанию)  ▲║
║  Классическая                ■     Cascadia Mono             ■║
║  Классическая, мягкие цвета  ▒     Consolas                  ▒║
║  Сумерки                     ▒     Courier New               ▒║
║  Чёрно-белая                 ▒     DejaVu Sans Mono          ▒║
║  Монохромная                 ▼     Lucida Console            ▼║
║                                                               ║
║ Размер шрифта  16       6–96; в окне: Ctrl+= / Ctrl+-         ║
║                                                               ║
║  Изменения видны сразу. «Отмена» вернёт прежние настройки.    ║
║                                        [  OK  ] [ Отмена ]    ║
╚═══════════════════════════════════════════════════════════════╝
```

Изменения применяются **сразу**, пока диалог открыт: перемещение по списку
тем перекрашивает программу, выбор шрифта или новое число в поле размера
перестраивают окно. «OK» оставляет выбранное, «Отмена» (или Esc) возвращает
всё как было.

## Подключение

Достаточно пункта меню и одной строки в обработчике:

```rust
use tvision_gui::*;

const CM_SETTINGS: u16 = 200;

fn menu() -> Menu {
    Menu::new().submenu(
        "~Ф~айл",
        Menu::new()
            .item("~Н~астройки...", CM_SETTINGS)
            .separator()
            .item_key("В~ы~ход", cm::QUIT, kb::ALT_X, "Alt-X"),
    )
}

struct App;

impl AppHandler for App {
    fn handle_event(&mut self, app: &mut Program, ev: &mut Event) {
        if ev.command() == Some(CM_SETTINGS) {
            settings_dialog(app);   // true — нажато OK, false — отмена
            ev.clear();
        }
    }
}
```

Так сделано в примерах: `hello` (меню «Привет → Настройки…»), `tvedit`
(«Файл → Настройки окна…»), `tvdemo` («Настройки → Шрифт и тема…»).

Надписи диалога — на языке надписей tvision-rs: по-русски при
`locale::set_language(locale::Language::Ru)`, иначе по-английски.

## Запоминание настроек

По умолчанию выбор, сделанный в диалоге и подтверждённый кнопкой «OK»,
записывается в файл и восстанавливается при следующем запуске программы:

| ОС | Файл |
|----|------|
| Windows | `%APPDATA%\tvision-gui\ИМЯ.conf` |
| macOS | `~/Library/Application Support/tvision-gui/ИМЯ.conf` |
| Linux, BSD | `$XDG_CONFIG_HOME/tvision-gui/ИМЯ.conf` (обычно `~/.config/tvision-gui/ИМЯ.conf`) |

ИМЯ — имя исполняемого файла без расширения (`tvdemo`, `dlgdsn` ...). Файл
текстовый:

```
# Настройки окна tvision-gui (диалог «Настройки»)
theme = Сумерки
font = C:\Windows\Fonts\CascadiaMono.ttf
font_size = 18
```

Пустое значение `font` — системный шрифт. Файл можно править вручную или
удалить, чтобы вернуться к настройкам из кода.

Порядок, в котором применяются настройки (каждый следующий важнее):

1. значения в коде — `GuiConfig::font`, `font_size`, `theme`, `palette`;
2. сохранённые в файле (если `GuiConfig::remember_settings` включено);
3. переменные окружения `TVISION_GUI_FONT` и `TVISION_GUI_FONT_SIZE`.

Отключить запоминание:

```rust
run(GuiConfig::new("Программа").remember_settings(false), app_main)
```

Тогда диалог по-прежнему меняет оформление, но только до выхода из программы.

## Темы

| Тема (русское / английское название) | Палитра программы | 16 цветов окна |
|--------------------------------------|-------------------|----------------|
| Gruvbox / Gruvbox | `color::palettes::GRUVBOX` (256 цветов) — **по умолчанию** | gruvbox |
| Классическая / Classic | `APP_COLOR` — цвета Turbo Vision | VGA |
| Классическая, мягкие цвета / Classic, soft colors | `APP_COLOR` | gruvbox |
| Сумерки / Dusk | `APP_COLOR`, перекрашенная в 256 цветов (`color::remap`) | VGA |
| Чёрно-белая / Black and white | `APP_BLACK_WHITE` | VGA |
| Монохромная / Monochrome | `APP_MONOCHROME` | VGA |

Тема — это две палитры сразу: **палитра программы** (`Program::palette`,
135 атрибутов) решает, какие цвета получают меню, рамки, кнопки, а
**16 цветов окна** — как выглядят на экране цвета BIOS 0–15. Подробнее — в
[разделе 3](03-configuration.md#палитра).

Начальная тема задаётся в коде:

```rust
run(GuiConfig::new("Программа").theme("Классическая"), app_main)
```

Название ищется без учёта регистра, по-русски или по-английски
(`"classic"` тоже подойдёт).

## Список шрифтов

В списке — все моноширинные шрифты с обычным начертанием, найденные в
каталогах шрифтов системы (тех же, что в [разделе 6](06-rendering.md#поиск-шрифтов),
включая шрифты, установленные только для пользователя). Моноширинность
определяется по самому файлу (признак `isFixedPitch` в таблице `post` или
`panose` в таблице `OS/2`); известные моноширинные шрифты попадают в список
всегда. Жирные и курсивные начертания, цветные шрифты эмодзи в список не
входят.

Файлы шрифтов не загружаются целиком — из каждого читаются только нужные
таблицы, поэтому диалог открывается быстро и при сотнях шрифтов. Список
строится один раз за время работы программы.

## Те же действия из кода

| Функция | Что делает |
|---------|-----------|
| `settings_dialog(app) -> bool` | открыть диалог |
| `themes() -> Vec<Theme>` | встроенные темы |
| `find_theme(name) -> Option<Theme>` | тема по названию |
| `apply_theme(app, &theme)` | применить тему (палитра программы и окна) |
| `set_window_palette([u32; 16])` | сменить только 16 цветов окна |
| `set_font(Option<&Path>, size)` | сменить шрифт и размер (`None` — системный) |
| `current_settings() -> Option<GuiSettings>` | текущие тема, шрифт, размер |
| `GuiSettings::load()` / `save()` / `path()` | файл настроек программы |
| `monospace_fonts() -> Vec<FontInfo>` | моноширинные шрифты системы |
| `apply_saved_settings(app)` | применить тему из настроек к программе, созданной через `Program::new` |

`Program::with_window` применяет тему из настроек сам. Если программа
создаётся через `Program::new(GuiBackend::boxed()?, ...)`, вызовите после
этого `apply_saved_settings(&mut app)` — иначе палитра программы останется
палитрой по умолчанию, хотя шрифт и цвета окна восстановятся.

### Своя тема

```rust
let night = Theme {
    name: "Ночь",
    name_en: "Night",
    app_palette: color::remap(color::palettes::APP_COLOR, &[
        233, 24, 65, 30, 124, 90, 130, 250, 240, 68, 108, 73, 167, 133, 179, 255,
    ]),
    window_palette: VGA_PALETTE,
};
apply_theme(app, &night);
```

Своя тема в диалоге не показывается и в файл настроек записывается только
по названию — при следующем запуске она не найдётся среди встроенных.
Для постоянного выбора используйте встроенные темы или задавайте свою
в коде при каждом запуске.
