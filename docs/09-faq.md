# 9. Вопросы и проблемы

### Надписи библиотеки (кнопки «Cancel», диалог «Open file») остались английскими

Язык выбирается вызовом `locale::set_language(locale::Language::Ru)` — в
`main` до `run` или в `app_main`. Если он вызван в каком-то **третьем**
потоке (например, в `std::thread::spawn` внутри программы), на поток
программы он не действует: язык хранится отдельно для каждого потока.
См. [раздел 2, шаг 5](02-porting.md#шаг-5-язык-надписей).

### Пример tvision-rs не находит файл из командной строки

Сгенерированные примеры запускаются из каталога tvision-gui, поэтому пути из
описаний примеров tvision-rs (`examples/data/books.json`) нужно начинать с
`../tvision-rs/`:

```
cargo run --example json_table -- ../tvision-rs/examples/data/books.json
```

Файлы, которые пример открывает сам (образцы данных), находятся
автоматически.

### Вместо некоторых символов — «квадратики»

Символа нет ни в основном, ни в запасных шрифтах. Варианты:

* установить шрифт с нужными символами (для иероглифов — Noto CJK, MS Gothic);
* указать шрифт явно: `GuiConfig::font(...)` или `TVISION_GUI_FONT`.

Рамки и блоки псевдографики от шрифта не зависят.

### Окно не закрывается крестиком

Крестик посылает программе команду `cm::QUIT`. Если открыт модальный диалог,
он может её не пропустить: закройте диалог (Esc) и нажмите крестик ещё раз.
Если программа зависла и не рисует ничего больше 2 секунд, повторное нажатие
на крестик завершает процесс принудительно.

### Рядом с окном открывается окно консоли (Windows)

Добавьте в начало `main.rs`:

```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]
```

### На macOS ошибка «окно должно работать в главном потоке»

Программа вызвала `with_window` без `run`. Оберните `main`:
`run(GuiConfig::new("..."), app_main)`.

### Паника «не удалось создать цикл событий окна» (Linux)

Нет графического сеанса (SSH без X11, консоль без Wayland). Запускайте
терминальную версию программы — см. [раздел 8](08-platforms.md#без-графического-сеанса).

### Шрифт слишком мелкий или крупный

* во время работы — Ctrl+= / Ctrl+- / Ctrl+0;
* в коде — `GuiConfig::font_size(px)`;
* без перекомпиляции — `TVISION_GUI_FONT_SIZE=20`.

На мониторах с масштабом 150–200 % размер автоматически умножается на масштаб.

### Как сделать 43 или 50 строк, как в DOS

`tvision_gui::set_screen_size(80, 50)` — окно подстроится под 50 строк
текущего шрифта. Или увеличьте окно мышью / разверните его.

### Окна на рабочем столе не растягиваются вместе с окном программы

Так и в Turbo Vision: при изменении размера экрана перестраиваются рабочий
стол, строка меню и строка состояния, а окна сохраняют свои размеры.
Разверните окно (F5 / двойной щелчок по заголовку) или вызовите «Мозаику».

### Программа медленно рисует при первом запуске

Отладочная сборка растеризует шрифт заметно медленнее. Используйте
`cargo run --release`. Символы растеризуются один раз, дальше берутся из кэша.

### После обновления tvision-rs примеры не собираются или ведут себя по-старому

Пересоздайте их: `cargo run --example sync_examples`. Проверить без записи —
`cargo run --example sync_examples -- --check`.

### Можно ли вводить иероглифы через метод ввода (IME)?

Пока нет: ввод идёт посимвольно с клавиатуры. Иероглифы, вставленные из
буфера обмена или прочитанные из файла, отображаются (через запасные шрифты).

### Можно ли запустить две программы (два окна) в одном процессе?

Нет: одна программа `Program` — одно окно, и `run` вызывается один раз за
время работы процесса.

### Можно ли рисовать в окне графику (не символы)?

Нет: tvision-gui показывает только сетку символов Turbo Vision. Программа
по-прежнему работает «в ячейках».

### Как поменять заголовок окна во время работы

`tvision_gui::set_title("Новый заголовок")` — из любого потока.

### Как вывести отладочную информацию

`eprintln!` в отладочной сборке пишет в консоль, из которой запущена
программа (в Windows — в окно консоли рядом с окном программы). На экран
Turbo Vision это не влияет — в отличие от терминальной версии, где вывод
в stderr портит изображение.
