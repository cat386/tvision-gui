# 10. Примеры

## Два вида примеров

| Вид | Файлы | Откуда |
|-----|-------|--------|
| написанные для tvision-gui | `hello.rs`, `tvedit.rs`, `tvdemo/` | версии примеров tvision-rs, полностью на русском (включая справку tvdemo) |
| сгенерированные | все остальные `examples/*.rs` с первой строкой `// СГЕНЕРИРОВАНО sync_examples` | примеры tvision-rs без изменений кода, только в окне |
| генератор | `sync_examples.rs` | пересоздаёт сгенерированные примеры |

Запуск любого примера — из каталога tvision-gui:

```
cargo run --example ИМЯ
cargo run --release --example ИМЯ    # быстрее, особенно при первом показе символов
```

## Список

### Написанные для tvision-gui

| Пример | Что показывает |
|--------|----------------|
| `hello` | «Привет, мир!» — меню, диалог с кнопками (Alt+G) |
| `tvedit` | многооконный редактор: файлы, поиск и замена, буфер обмена |
| `tvdemo` | калькулятор, календарь, пятнашки, таблица ASCII, просмотр файлов, настройки цветов и мыши, справка F1 |

### Из tvision-rs

| Пример | Что показывает | Клавиши |
|--------|----------------|---------|
| `learn_01_hello` | урок 1: пустой рабочий стол и строка состояния | Alt+X |
| `learn_02_menu` | урок 2: меню, строка состояния, свои команды | F10, F2 |

| `learn_04_coords` | урок 4: координаты; щелчки мышью показывают позицию | F2, щелчки |
| `learn_05_dialog` | урок 5: диалог — спросить имя и поздороваться | F2 |
| `learn_06_form` | урок 6: анкета — флажки, переключатели, список | F2 |
| `learn_07_view` | урок 7: своё представление — счётчик | Пробел, Enter, `-`, `0`, Tab |
| `learn_08_todo` | урок 8: своё окно с данными — список дел | Ins, F4, Del, F3 |
| `guide_contacts` | урок 9: записная книжка «Контакты» | см. окно |
| `demo` | окна, меню, диалог со всеми элементами, список, контекстное меню, справка | F2, F3, Alt+D, правая кнопка |

| `three_panes` | окно из трёх частей: дерево, таблица и строка ввода | Tab, мышь |

| `json_table` | файл JSON в таблице | F3 |
| `json_load` | загрузка большого JSON в потоке с полосой выполнения | F2, F3 |

Не переносится утилита `tvhc` (проверка файлов справки): она работает в
командной строке, и окно ей не нужно — запускайте её из tvision-rs.

### Аргументы командной строки

Примеры запускаются из каталога tvision-gui, поэтому пути из описаний
tvision-rs начинайте с `../tvision-rs/`:

```
cargo run --example json_table -- ../tvision-rs/examples/data/books.json
cargo run --example treeview  -- C:\Users
cargo run --example lfm       -- D:\develop D:\develop\rust
```

Образцы данных, которые пример открывает сам (например, «книги» в
`treeview`), находятся автоматически.

## Как устроен сгенерированный пример

Сгенерированный файл — это исходник примера tvision-rs, в котором заменено
несколько мест:

| В tvision-rs | В tvision-gui |
|--------------|---------------|
| `Program::with_terminal(menu, status)` | `<Program as tvision_gui::ProgramExt>::with_window(menu, status)` |
| `platform::default_backend()` | `tvision_gui::GuiBackend::boxed()` |
| `fn main() -> R { ... }` | `fn tv_main() -> R { ... }` и новый `main`: `tvision_gui::run(GuiConfig::new("заголовок"), tv_main)` |
| `mod json;`, `#[path = "json/mod.rs"]` | `#[path = "../../tvision-rs/examples/json/mod.rs"]` |
| `include_str!("файл")` | `include_str!("../../tvision-rs/examples/файл")` |
| `env!("CARGO_MANIFEST_DIR")` | `concat!(env!("CARGO_MANIFEST_DIR"), "/../tvision-rs")` |

Заголовок окна — первая строка документации примера (`//! ...`).

Весь остальной код — представления, обработчики, потоки, тесты — остаётся
как есть. Это и проверка совместимости: если пример tvision-rs работает в
терминале, он работает и в окне. Тесты примеров (`#[cfg(test)] mod tests`)
сохраняются в файле, но запускаются в tvision-rs (`cargo test --examples`
там): они используют `HeadlessBackend` и окна не открывают.

## Генератор `sync_examples`

```
cargo run --example sync_examples              # пересоздать примеры
cargo run --example sync_examples -- --check   # только проверить
```

Что делает:

1. читает все `../tvision-rs/examples/*.rs`;
2. пропускает `hello`, `tvedit`, `tvdemo` (свои версии), `tvhc` и примеры,
   которые не создают программу Turbo Vision;
3. для остальных пишет `examples/ИМЯ.rs`, если содержимое изменилось;
4. **не трогает** файлы без метки `// СГЕНЕРИРОВАНО sync_examples` — если
   какой-то пример переписан для окна вручную, удалите метку, и генератор
   его больше не перезапишет.

С ключом `--check` ничего не пишет и завершается с ошибкой, если
какой-то пример устарел — удобно для проверки перед коммитом.

Запускайте генератор после каждого обновления tvision-rs, в котором
появились или изменились примеры. Новые примеры подхватываются
автоматически: Cargo сам находит файлы в `examples/`.

## Свой пример: с нуля

Новый пример для окна проще написать сразу «по-оконному» (см.
[раздел 1](01-getting-started.md#первая-программа)) и положить в
`examples/` без метки — генератор его не тронет.
